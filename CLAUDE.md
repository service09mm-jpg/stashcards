# StashCards

PWA для карток лояльності. Працює повністю офлайн, бекенду немає.
Що і як — у `README.md`.

## Стек

- Vite + React 19 + TypeScript, Tailwind CSS v4
- `vite-plugin-pwa` (Workbox) — манифест і service worker
- Dexie (IndexedDB) — сховище, `src/lib/db.ts`
- `bwip-js` — генерація штрихкодів, `src/lib/barcode.ts`
- `zxing-wasm` + `BarcodeDetector` — сканування, `src/lib/scanner.ts`
- Vitest + Testing Library (`src/**/*.test.{ts,tsx}`), Playwright (`e2e/*.spec.ts`)

## Чого не можна ламати

- **Жодного мережевого запиту після завантаження.** У цьому весь сенс
  застосунку. Будь-яка бібліотека, що тягне щось із CDN у рантаймі, не
  підходить — `zxing-wasm` довелося окремо перенаправляти на локальний файл
  (див. `loadZXing` у `src/lib/scanner.ts`).
- **`e2e/offline.spec.ts` має проходити.** Це єдина перевірка, яка
  підтверджує головну властивість застосунку.
- **Екран картки лишається білим.** Це не оформлення, а вимога сканерів кас.
- **Імпорт штрихкодів тільки поіменний.** `toSVG()` з bwip-js посилається на
  всі сто з гаком символогій, і збірка важчає вчетверо.
- **Розмір збірки.** Список карток не повинен тягнути за собою генератор
  штрихкодів і wasm-декодер — вони підвантажуються окремо (`src/App.tsx`).
- **Порядок карток змінює тільки юзер.** Жодного автоматичного сортування:
  ані за частотою, ані за датою, ані «розумного». Це була окрема вимога.
- **Кнопки «назад» знімають запис з історії, а не додають новий.**
  `useBack()`, ніяких `<Link to="/">` у ролі «назад»: інакше системна кнопка
  на Android водить юзера по всіх раніше відкритих картках.
- **Плитка картки — кнопка, а не посилання.** Після перетягування браузер
  надсилає `click`; dnd-kit гасить його поширення, але не стандартний перехід
  за `href`, тож `<a>` відкривав би картку замість того, щоб переставити її.
- **Ніякого `PointerSensor`, тільки `MouseSensor` + `TouchSensor`.** Перший
  скасовує перетягування на `pointercancel`, а саме її браузер надсилає,
  коли забирає жест під гортання, — на телефоні перетягування не працює
  взагалі. Перевіряється сенсорними тестами в `e2e/ordering.spec.ts`; на
  миші обидва варіанти поводяться однаково, тож тести мишею тут нічого не
  доводять.

## Домовленості

- Коментарі пояснюють *чому*, а не *що*. Мова коментарів і інтерфейсу —
  українська.
- Кожна нова можливість отримує щонайменше один тест.
- Комміти дрібні, по одній зміні.
- Перед пушем: `npm run lint && npm run test && npm run build && npm run test:e2e`.

## Модель даних

`Card` має `updatedAt` і `deletedAt`, хоча синхронізації ще немає. Це
навмисно: домалювати її пізніше без міграції чужих баз у браузерах інакше не
вийде. Видалення м'яке, ідентифікатори — UUID.
